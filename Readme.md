# Hurlaz

> Project Objective

Hurlaz is a github custom actions that give the ability to use `hrul` script
in test via use case

> Project Setps

1. Take the Version For Hurl Download it
2. Run Local Version From Project Via DockerCompose
3. Run Hurl Script Provide `hurl-pattern` to can find the scripts like "test/\*_/_.hurl"
4. Collect The Output Report For User .
5. Shutdown the local Project
